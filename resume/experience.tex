          \begin{itemize}

            \begin{itemize}
              \item 项目初期，对 Mesa/Gallium 的 swrast (软渲染) 驱动及 pipe-loader, winsys, driconf 及构建系统等代码集中学习分析之后，
              在一个月时间内由攻坚小组(共 4 人)完成基本框架和功能的编码，glxgears 可以正常运行。
              \item 对 Indirect Draw, Geometry Shader, Transfrom Feedback, Tessellation Shader 功能进行了实现和移植，Indirect Draw
              复用了 mesa/util 的 util\_draw\_indirect() 实现，Tessellation Shader 复用了 Microsoft 的 C++ tessellator 细分器实现。
              在这些主要功能实现后，glmark2 的大部分 场景都正常运行
              \item 项目中后期主要是修复测试出来的 Bug, 测试集包括 glxgears, glmark2, CTS, KC-CTS, piglit, 其中 CTS 通过率 94\%
              \item 客户适配阶段主要是性能分析和优化，使用包括 apitrace, perf/flamegraph, JDX 等工具找到热点函数，进行代码重构和 CPU/GPU 硬件相关的一些优化。
              \item 项目过程也整理了不少学习笔记和内部文档，以及代码仓库的 clean code, 如 clang-format, 还有 workflow 的制定。
            \end{itemize}
            \item KMD:
            \begin{itemize}
              \item 熟悉了 DRM 子系统的 drm\_gpu\_scheduler 和 TTM/GEM 内存管理器，DMA-BUF 子系统的 buffer import/export 流程，dma\_fence 的工作机制等
              \item 了解了 GPU 同步中使用的 drm\_syncobj, 及 implicit sync 和 explicit sync 的区别
              \item 了解了内核 Memory Shrinker 及在 drm\_gpu\_scheduler 中申请内存时的限制
              \item 了解了 KMS 的 Atomic commit, 以及 KMS 与 X11 DDX 的关系
            \end{itemize}
            \item 其它:
            \begin{itemize}
              \item 利用 ARM 向量指令 NEON 优化的 string.h 的实现版本，加速 CPU 访问内存
              \item 了解了 ARM 平台的 Device-GRE 和 X86-64 平台的 Write-Combining 非 Cache 内存类型
              \item GPU 中的一些硬件设计的原理
            \end{itemize}
